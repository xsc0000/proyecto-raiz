# 📚 Librería Independiente Raíz

## Descripción

Este proyecto corresponde al desarrollo de un sitio web estático para la **Librería Independiente Raíz**, realizado como parte de la actividad de la asignatura **Metodología de Software**.

El objetivo principal fue corregir la estructura del proyecto para permitir su publicación mediante **GitHub Pages**, aplicando buenas prácticas de desarrollo web.

---

## Objetivos

- Implementar una estructura organizada de carpetas.
- Utilizar HTML5 semántico.
- Aplicar estilos con CSS3.
- Incorporar interactividad mediante JavaScript.
- Emplear rutas relativas compatibles con GitHub Pages.
- Facilitar el despliegue del sitio desde la rama `main`.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador.

También puede publicarse directamente mediante GitHub Pages.
